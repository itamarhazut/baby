# התינוק שלנו: הוראות התקנה

אפליקציה שמותקנת על הטלפון (אייפון וגלקסי), שומרת את הכול ב-Supabase ומסתנכרנת בין שניכם.

מה בתיקייה:

| קובץ | מה זה |
|---|---|
| `index.html` | האפליקציה עצמה |
| `config.js` | כאן מדביקים את הפרטים של Supabase |
| `supabase/schema.sql` | הקמת מסד הנתונים וההרשאות |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | מה שמאפשר להתקין על מסך הבית ולפתוח מהר |
| `vendor/supabase.js` | ספריית Supabase (כבר כלולה, אין צורך להוריד כלום) |

צריך שלושה דברים: פרויקט Supabase, מקום להעלות אליו את התיקייה, והטלפונים שלכם. כל זה בחינם.

---

## שלב 1: פרויקט Supabase

1. נכנסים ל-supabase.com ופותחים **New project** (שם חופשי, למשל `baby`, וסיסמה לבסיס הנתונים שאפשר לשמור בצד).
2. מחכים כמה דקות עד שהפרויקט מוכן.
3. בתפריט הצד: **SQL Editor** ואז **New query**.
4. פותחים את `supabase/schema.sql`, מעתיקים את כל התוכן, מדביקים ולוחצים **Run**. אמור להופיע "Success".

## שלב 2: חיבור האפליקציה

1. ב-Supabase: **Project Settings** ואז **API** (בחלק מהגרסאות: כפתור **Connect** למעלה).
2. מעתיקים את **Project URL** ואת המפתח הציבורי (**anon public**, בגרסאות חדשות נקרא גם **publishable key**).
3. פותחים את `config.js` בעורך טקסט ומחליפים את שני הערכים. שומרים.

המפתח הזה ציבורי מעצם תכנונו. מי שיש לו אותו עדיין לא יכול לקרוא נתונים בלי להתחבר, וגם אחרי התחברות רואים רק את המשפחה שלהם.

## שלב 3: החלטה על אישור מייל

ב-Supabase: **Authentication** ואז **Sign In / Providers** ואז **Email**.

- אם **Confirm email** דלוק: כל אחד מכם יקבל מייל אישור אחרי יצירת החשבון.
- אם תכבו אותו: כניסה מיידית. נוח יותר לשניים בבית, וקצת פחות בטוח.

## שלב 4: העלאה לאינטרנט

האפליקציה צריכה כתובת אינטרנט כדי להתקין אותה על הטלפון. הדרך הכי קלה:

**Netlify Drop**: נכנסים ל-app.netlify.com/drop, גוררים את **כל התיקייה** (אחרי שמילאתם את `config.js`) לחלון, ומקבלים כתובת. אפשר לשנות אותה בהגדרות האתר.

אלטרנטיבות שוות ערך: Cloudflare Pages או GitHub Pages. זה אתר סטטי, אז כל אחת מהן עובדת.

כשתרצו לעדכן את האפליקציה: מעלים את התיקייה מחדש לאותו אתר.

## שלב 5: התקנה על הטלפונים

- **אייפון:** פותחים את הכתובת ב-**Safari**. כפתור השיתוף ואז **הוספה למסך הבית**.
- **גלקסי:** פותחים בכרום. תפריט ⋮ ואז **התקנת אפליקציה** (או **הוספה למסך הבית**).

## שלב 6: חיבור שניכם

1. אחד מכם (נניח אתה) יוצר חשבון (אימייל וסיסמה), ובמסך הבא לוחץ **יצירת משפחה חדשה**.
2. ממלא את פרטי התינוק. הכול נשמר בענן.
3. נכנס להגדרות (⚙️ למעלה) ומעתיק את **קוד ההזמנה**.
4. אשתך פותחת את האפליקציה, יוצרת חשבון משלה, ובמסך "עוד צעד קטן" מקלידה את הקוד ולוחצת **הצטרפות**.

מאותו רגע שניכם רואים ועורכים את אותם נתונים, ושינוי של אחד מופיע אצל השני תוך שניות.

---

## איך הנתונים נשמרים ואיך מגבים

- הכול נשמר ב-Supabase, ולא במכשיר. ניקוי דפדפן, החלפת טלפון או מחיקת האייקון לא מוחקים כלום. נכנסים שוב עם אותו חשבון וחוזר הכול.
- Supabase בתוכנית החינמית **משהה פרויקט שלא היה בו שימוש שבוע**, וזה לא יקרה לכם בשימוש רגיל. אם בכל זאת יקרה, אפשר להפעיל אותו מחדש בלוח הבקרה והנתונים נשמרים.
- **גיבוי:** בלוח הבקרה, **Table Editor**, אפשר לייצא כל טבלה (`app_state`, `log_entries`) ל-CSV. בתוכניות בתשלום יש גיבוי אוטומטי יומי.
- אם שניכם עורכים בדיוק את אותו חלק באותה שנייה, העריכה האחרונה גוברת.

## פתרון בעיות

- **"חסר חיבור ל-Supabase"**: `config.js` לא מולא או שהועלתה גרסה ישנה.
- **"אימייל או סיסמה שגויים"** אחרי יצירת חשבון: אולי צריך לאשר את המייל (שלב 3).
- **לא רואים עדכונים של בן או בת הזוג**: ודאו שבפינה כתוב "מסונכרן ✓", ושהשניים מחוברים לאותה משפחה (אותו קוד).
- **באייפון האפליקציה לא מתעדכנת אחרי העלאה מחדש**: סוגרים אותה לגמרי ופותחים שוב.
